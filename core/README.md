# Core — F#

Implementaciones de los módulos principales en **F# (.NET 10)**, ejecutados con el SDK de .NET (`dotnet fsi`, `dotnet test`).

---

## 📂 Módulos / Modules

| Módulo | Descripción |
|--------|-------------|
| [`foundations/`](foundations/) | **Fase 0 — Fundamentos**: `helloworld`, `hellouser`, `calculator`, `numbers` |

---

### ▶️ Comenzar / Getting Started

```bash
# Hello, World!
cd foundations/helloworld
dotnet fsi hello-world.fsx

# Hello, User!
cd foundations/hellouser
dotnet fsi hello-user.fsx

# Calculator Tests
cd foundations/unit_test/calculator
dotnet test calculator.slnx

# Numbers Tests
cd foundations/numbers
dotnet test numbers.slnx
```
